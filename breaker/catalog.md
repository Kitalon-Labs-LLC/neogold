# NeoGold Breaker Catalog (`breaker/catalog.md`, P27)

Every entry defines a white-box or black-box adversarial probe executed by the `breaker` agent (`/ng-break`) on disposable copies with synthetic data only. Every break discovered becomes a failing regression test citing the `TC-`, `T`, or `H` ID it protects before any fix is written.
