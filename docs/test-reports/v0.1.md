## 0. Mandatory Clinical Disclaimer

> [!CAUTION]
> **Software testing cannot show that NeoGold is clinically safe.**
>
> Model v1 is trained on synthetic and pilot calibration data and has **no clinical meaning yet**. Clinical validity and diagnostic accuracy (sensitivity, specificity, Bland-Altman agreement with total serum bilirubin) require partner Phase B clinical validation under institutional ethics approval in Bangladesh before any clinical reliance.
>
> This v0.1 milestone verifies exclusively that the software and algorithmic pipeline functions correctly, deterministically, and within memory and latency budgets on the target device hardware matrix.

## 4. Determinism, Parity, and Offline Verification

### 4.1 Golden Vector Parity (TC-EST-01)
- Golden reference skin patch Lab: `[62.27276993, 10.71970422, 26.04906880]`.
- Extracted features ($L^*, a^*, b^*, b^*/L^*, a^*/b^*$) matched golden vectors within $1 \times 10^{-6}$ (tolerance: $1 \times 10^{-4}$).

### 4.2 Multi-ABI Determinism (TC-EST-07)
Evaluated across 10 golden vector combinations covering low risk, intermediate risk, high risk, and urgent referral boundaries:
- Floating-point calculations implemented via `java.lang.StrictMath` guarantee identical bitwise float behavior on `arm64-v8a` (64-bit ARM) and `armeabi-v7a` (32-bit ARM).
- Bilirubin estimates matched to the exact integer-tenth ($0.1\text{ mg/dL}$) on both ABIs.
- Triage actions and reason codes were 100% identical.

### 4.3 Zero Network Transmission (TC-EST-04)
- Network sandbox test confirmed that the screening pipeline, state machine, and debug screen make **0 HTTP, HTTPS, DNS, or TCP socket connections**.
- All screening models, triage boundaries, and calibration assets execute completely on-device.

### 4.4 Quality Gate Rejection (TC-CAP-11)
- 16 negative test frames (synthetic and phantom bench captures with glare, excessive blur, tilt $> 15^\circ$, underexposure, overexposure, cloth obstruction, missing card) were evaluated through the Vision Engine.
- **Rejection rate: 100% (16/16 rejected)**. Each rejection emitted the exact expected reason code (`GLARE`, `BLUR`, `CARD_TILT`, `UNDEREXPOSED`, `OVEREXPOSED`, `NO_CARD`, `INVALID_SKIN_WINDOW`).
