# NeoGold Model Training Pipeline

This directory contains the Python training pipeline and pinned environment for the bilirubin estimation model.

## Contents
- Pinned dependency definitions (`pyproject.toml` or `requirements.txt`)
- Dataset loader for paired bench and study data
- Feature extraction and regression model training scripts
- Export to canonical `model.json` format (defined in doc 4 Section 7.2)

## Work Packages
- **P07**: Training pipeline implementation, reproducibility tests, and bench phantom validation
