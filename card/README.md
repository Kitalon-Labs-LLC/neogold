# NeoGold Color Calibration Card

This directory contains the physical card v1 design, specifications, and offline card signing tool.

## Contents
- Card geometry, layout, and print specifications (PDF/SVG, CMYK/spot color targets)
- Card QR payload definition and Ed25519 digital signature scheme
- `neogold-sign`: Offline CLI tool for signing card batches and study enrollment profiles

## Work Packages
- **P02**: Card v1 layout, physical patch positions, markers, and QR code format specifications
- **P05**: Card trust engine, batch generation, and `neogold-sign` tool
